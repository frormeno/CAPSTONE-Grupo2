# SIGIOP – Sistema de Gestión de Información Operacional

Proyecto desarrollado como parte del **Capstone de Ingeniería en Informática – Duoc UC**, orientado al diseño e implementación de una solución tecnológica para el **Ministerio de Obras Públicas (MOP)**.

---

## 📌 Descripción

**SIGIOP** busca centralizar, gestionar y visualizar información operacional que actualmente se encuentra distribuida entre formularios, archivos y planillas Excel.

La solución considera una plataforma web y una aplicación móvil que permitan apoyar los procesos de registro, consulta, seguimiento y gestión de información operacional.

---

## 🎯 Objetivo

Diseñar e implementar una plataforma que permita mejorar la disponibilidad, organización y trazabilidad de la información operacional, facilitando su consulta y gestión mediante herramientas web y móviles.

---
